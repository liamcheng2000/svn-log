# SVN 日志导出工具 使用说明

**版本：v1.1.2　适用平台：Windows 10 / 11**

## 一、软件简介

本工具用于从 SVN 仓库批量导出提交日志，按扩展名过滤（默认只保留 `.cpp` / `.h` 文件），并生成一份包含「基本信息、日志明细、版本汇总」三页的 Excel 报表，便于代码走查、版本回顾和测试记录。

主要功能：

- 支持按**日期范围**或**版本范围**查询（二选一）
- 自动过滤文件类型，过滤规则可自定义
- 导出三页 Excel：基本信息、日志明细、版本汇总
- 提交说明中的关键字段自动**加粗并分段**
- 后台查询，显示进度，支持随时取消
- 复用 SVN 已缓存的认证信息，无需重复登录

## 二、运行环境

- Windows 10 / Windows 11（64 位）
- 已安装 TortoiseSVN（工具需要其中的 `svn.exe`，也可以手动指定其他 `svn.exe`）
- Microsoft Excel 2016 及以上，或支持富文本的 WPS
- 使用 exe 版本时无需安装 Python

## 三、启动软件

双击 `SVN日志导出.exe` 即可启动。

单文件版本首次启动需要解压运行库，可能等待几秒钟，属于正常现象。

## 四、界面说明

### 4.1 SVN 配置

- **SVN 地址**：仓库地址，例如 `https://svn.example.com/repo/trunk`
- **测试连接**：验证地址、网络和认证是否可用，并显示 HEAD 版本号
- **svn.exe**：自动定位 TortoiseSVN 自带的 `svn.exe`；如果未找到，点击「浏览」手动指定

### 4.2 查询范围（二选一）

- **按版本范围**：填写起始版本和结束版本，可填数字或 `HEAD`
- **按日期范围**：填写起始日期和结束日期，格式为 `YYYY-MM-DD`
- 两种方式互斥，选择一种后另一种会自动置灰

### 4.3 输出设置

- **文件过滤**：默认 `.cpp;.h`
- **导出文件**：Excel 文件的保存路径
- **保留无匹配文件的版本**：勾选后，即使某次提交没有 cpp/h 文件，也会保留该版本记录
- **生成后自动打开 Excel**：默认勾选

### 4.4 操作按钮

- **开始导出**：执行查询并生成 Excel
- **取消**：中止正在进行的查询
- **打开认证终端**：认证失败时手动登录一次
- **打开输出目录**：打开导出文件所在文件夹
- **帮助**：打开本使用说明

## 五、快速上手

1. 填写 **SVN 地址**，点击「测试连接」确认可以访问。
2. 选择查询方式：
   - 版本范围两项留空 = 导出**最近 10 条**日志
   - 或选择日期范围并填写起止日期
3. 确认**文件过滤**规则（默认 `.cpp;.h`）。
4. 选择**导出文件**路径。
5. 点击「开始导出」，等待进度完成。
6. 导出完成后会自动打开 Excel（可在输出设置中取消）。

## 六、查询范围说明

### 6.1 按版本范围

- 起始、结束**都留空**：导出最近 10 条日志（HEAD-10 ~ HEAD）
- **只填起始**：起始版本 ~ HEAD
- **只填结束**：1 ~ 结束版本
- 版本号可填数字或 `HEAD`
- 起始版本不能大于结束版本

### 6.2 按日期范围

- 起始、结束**都留空**：导出全部历史
- 日期格式为 `YYYY-MM-DD`，也支持 `2026/1/5` 自动转换
- **结束日期包含当天 23:59:59**
- 起始日期不能晚于结束日期

### 6.3 时间与时区

- 日志时间按**本机时区**显示和换算
- 日期范围的边界按本地时间计算

## 七、文件过滤

- 默认过滤规则：`.cpp;.h`
- 分隔符支持分号、逗号、空格
- 写法支持 `.cpp`、`*.cpp`、`cpp`，不区分大小写
- 留空表示导出**全部类型**文件，导出前会弹窗确认
- 只统计文件变更，目录变更不计入日志明细

示例：

- 只导出 C++ 文件：`.cpp;.h;.hpp`
- 导出 C 文件：`.c;.h`
- 导出全部：留空

## 八、Excel 报表说明

### 8.1 基本信息

包含：SVN 地址、查询模式与范围、文件过滤规则、返回版本数、导出文件数、新增/修改/删除统计、提交人数、版本区间、实际执行命令、svn.exe 路径、生成时间。

### 8.2 日志明细

**每个文件一行**，列依次为：

- 序号
- 版本号
- 作者
- 提交日期
- 提交说明
- 操作（新增 / 修改 / 删除 / 替换）
- 文件路径
- 扩展名

序号、版本号、作者、提交日期、操作、扩展名**居中**；提交说明和文件路径左对齐并自动换行。

### 8.3 版本汇总

**每个版本一行**，除基本信息外还包括：

- 文件数
- 新增 / 修改 / 删除文件数量
- 文件列表（单元格内换行）

表格底部带有合计行。

### 8.4 提交说明的加粗与分段

当提交说明中出现下列字段时，字段名会**加粗**并**另起一行**：

更改原因、修改原因、变更原因、问题单号、缺陷单号、需求单号、任务单号、更改措施、修改措施、解决方案、修改方案、影响范围、影响模块、桌面验证、验证情况、验证结果、测试情况、测试结果、测试说明、自测情况、自测结果、备注。

支持以下写法：

- `更改原因：空指针导致崩溃`
- `【更改原因】空指针导致崩溃`
- `更改原因` 单独占一行，内容写在下一行

同一行里写多个字段（如 `更改原因：xx 问题单号：123`）也会自动拆开。

不含上述字段的普通提交说明保持原样，不做拆分。

### 8.5 表格样式

- 首行冻结、自动筛选
- 同一版本的明细行交替底色
- 列宽与行高自动适配
- 日期格式为 `yyyy-mm-dd hh:mm`

## 九、认证与凭据

工具调用 `svn.exe` 时固定使用 `--non-interactive`，不会弹出交互窗口打断查询，而是直接复用 SVN 的认证缓存。

认证失败时按以下步骤处理：

1. 点击「打开认证终端」；
2. 在弹出的黑色窗口中按提示输入 SVN 账号和密码；
3. 命令结束后关闭该窗口；
4. 回到工具重新点击「开始导出」。

密码**不会**保存在本工具中。工具只在 `%APPDATA%\SVNLogApp\config.json` 中保存地址、查询范围、过滤规则、输出目录等偏好。

## 十、常见问题

### 10.1 提示「未找到 svn.exe」

点击「浏览」，选择 `C:\Program Files\TortoiseSVN\bin\svn.exe`；或安装 TortoiseSVN 后重启工具。

### 10.2 认证失败（E170001 / E215004）

服务器要求登录或凭据失效。点击「打开认证终端」手动登录一次，成功后重新导出。

### 10.3 证书校验失败（E230001）

服务器证书不受信任。请在 TortoiseSVN 中永久接受该证书，或联系管理员更换有效证书后重试。

### 10.4 无法连接（E170013 / E175002）

检查 SVN 地址是否正确、网络是否通畅、是否需要连接公司 VPN 或配置代理。

### 10.5 提示「没有匹配的日志」

该路径在指定范围内没有提交，或文件过滤规则太窄。可以：

- 放宽日期或版本范围
- 检查文件过滤规则
- 勾选「保留无匹配文件的版本」，确认版本是否存在

### 10.6 提示「Excel 文件被占用」

目标 xlsx 正在 Excel 或 WPS 中打开。关闭该文件后重新导出，或修改导出文件名。

### 10.7 Excel 提示「检测到错误 / 已修复记录：字符串属性」

这是 v1.0.1 及更早版本生成文件的问题，**v1.0.2 已修复**。请升级到最新版本后重新导出，旧的异常文件建议删除。

### 10.8 导出的时间与服务器不一致

日志时间会转换为本机时区显示，属于正常现象。如需对比服务器时间，请将系统时区调整一致。

### 10.9 查询很慢或卡住

大范围查询（如数万条版本）本身耗时较长，可以：

- 缩小日期或版本范围
- 点击「取消」随时中止
- 等待进度条和日志窗口提示

### 10.10 帮助窗口没有内容

使用说明随 exe 一起发布。如果通过源码运行，请确认项目根目录存在 `docs\user_manual.md`。

### 10.11 启动时报 NumPy / AVX2 错误

现象：双击 exe 后弹出「启动失败：依赖模块导入出错」，内容包含 `NumPy was built with baseline optimizations ... but your machine doesn't support: (AVX2)`。

原因：v1.1.0 及更早版本的打包环境误把 NumPy 打进了 exe，而 NumPy 2.x 要求 CPU 支持 AVX2，较老的 CPU 无法运行。

处理：升级到 **v1.1.1** 及以上版本（已从安装包中移除 NumPy，不依赖 CPU 指令集）。

## 十一、使用建议

- 首次使用先点「测试连接」，确认地址与认证正常
- 大范围导出前，先用小范围试跑
- 导出期间不要用 Excel 打开目标文件
- 输出文件重名时会提示是否覆盖，请确认后再继续
- 定期升级到最新版本，修复已知问题

## 十三、技术支持

反馈问题时请提供以下信息，便于快速定位：

- 软件版本（窗口标题栏中的 vX.X.X）

- 查询范围（日期或版本号）
